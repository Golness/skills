# HTML 技术方案

产出一份内容有依据、结构可审阅、浏览体验完整的中文技术方案 HTML。优先复用 [assets/technical-solution-template.html](assets/technical-solution-template.html)，替换其中的 `{{...}}` 占位内容并按实际方案增删章节，不要从空白页面重新搭建样式。

## 工作方式

1. 先确认需求、现有实现、影响范围和约束。涉及代码仓库时，以实际代码、配置、数据库脚本和项目文档为证据；无法确认的内容明确标注为“待确认”，不要编造接口、字段或调用链。
2. 根据本次任务选择内容主线和章节。章节名称、数量、顺序及层级由方案本身决定，不套用固定目录。
3. 将内容填入模板。保持单文件交付：CSS 和 JavaScript 内嵌，favicon 使用 data URI。只有确有必要时才引入外部脚本；即使外部资源加载失败，正文和目录仍须可读。
4. 总览卡片是可选展示；使用时数量不限，统计值必须能从正文核对，避免装饰性数字。
5. 生成后运行校验脚本，并在浏览器中检查桌面宽度与窄屏布局。

## 必须满足的页面契约

- 文件扩展名为 `.html`，UTF-8 编码，`<html lang="zh-CN">`。
- `<title>` 与页面可见的唯一主标题 `<h1>` 含义一致。
- `<head>` 包含 `rel="icon"`；默认使用模板中的内嵌 SVG favicon，避免旁置图片丢失。
- 桌面端采用全宽布局，不设置固定内容最大宽度；页头、总览、目录和正文随视口伸展，仅保留响应式左右留白。目录保持稳定宽度，正文占据其余可用空间。
- 首屏包含标题和简短摘要；日期、版本、技术栈、统计卡片等元信息按任务需要选用。
- 正文包含清晰可识别的总览或概览，帮助读者快速理解方案。总览的位置、标题、表现形式和包含维度不作固定限制，也不要求必须是第一章。
- 页面包含“文档目录”。目录由正文 `h2`、`h3`、`h4` 自动生成，不手写两份章节名称。
- 桌面端目录使用 `position: sticky` 跟随页面滚动；正文滚动时当前章节自动高亮，目录较长时只滚动目录面板以让当前项可见，不能带动正文跳动。
- 目录链接支持平滑锚点跳转；标题设置 `scroll-margin-top`，避免跳转后贴顶。
- 窄屏下目录退化为正文上方的普通区块，不遮挡正文。
- 表格和代码块可横向滚动；提供打印样式，打印时隐藏交互控件和侧栏。
- 代码块使用 Highlight.js 进行语法高亮，并为代码元素标注语言类名，例如 `<pre data-language="Java"><code class="language-java">...</code></pre>`。至少覆盖 Java、SQL、JSON、XML、YAML、Shell、JavaScript 和纯文本；高亮库加载失败时仍须保留清晰可读的基础代码样式。
- 页面不依赖构建工具，直接双击即可阅读；控制台不应出现由页面自身代码导致的错误。

## 内容组织原则

- 目录完全来源于正文标题。不要为了匹配模板而创建空章节，也不要强制使用“背景、总体设计、数据、接口、测试、发布”等固定命名或固定顺序。
- 按读者完成评审所需的信息来组织正文。例如，小型配置调整可以只有总览、改动说明和验证方式；跨模块改造可按业务流程、模块、数据或发布阶段展开。
- 标题层级保持连续，不从 `h2` 跳到 `h4`；同级标题应采用一致的划分维度。
- 仅在有助于理解时使用表格、流程图、状态图、代码或 SQL，不要求每份方案具备这些元素。
- 对实际涉及的数据变更、兼容性、风险、测试或发布事项给出必要说明；不涉及的内容无需为了目录完整性而补写。

## 模板使用约定

- 替换所有 `{{...}}` 占位符，不在交付文件中遗留示例文本。模板正文只提供总览容器和自由章节插槽，可任意增删标题。
- 正文放在 `#content` 内。目录脚本只读取 `#content h2, #content h3, #content h4`。
- 保留 `#toc`、`#toc-count`、`.sidebar`、`.progress` 等模板钩子；若调整名称，要同步修改脚本。
- 标题可自带稳定 `id`。没有 `id` 时脚本会生成 `heading-N`；不要让两个标题使用相同 `id`。
- 若加入 Mermaid，采用渐进增强：图表源代码在渲染失败时仍可见，并根据明暗主题选择主题。
- 代码内容必须先进行 HTML 转义，尤其是 `<`、`>` 和 `&`；根据代码真实语言设置 `language-*`，无法判断时使用 `language-plaintext`，不要依赖自动语言猜测。
- 引用本地需求或脚本时使用相对链接，确保 HTML 与关联文件一起移动后仍可访问。

## 验证

运行：

```bash
python $HOME/.agents/skills/technical-solution-html/scripts/validate_html.py <生成文件.html>
```

校验通过后，再人工确认：

- 页面标题与 favicon 出现在浏览器标签页；
- 首屏摘要和正文“方案总览”都存在；
- 点击目录能准确跳转；连续滚动正文时，高亮项和目录面板会自动跟随；
- 目录超出视口时，目录自身滚动而正文位置不抖动；
- 约 390px 宽度下无正文遮挡，表格与代码块可横向滚动；
- Java、SQL 等代码块有清晰的关键字、字符串、注释和数字配色；断网时代码仍可阅读；
- 宽屏下页面能利用完整视口宽度，不应被固定在居中的窄内容区；
- 打印预览中正文完整，目录、主题按钮、返回顶部按钮和进度条隐藏。

如项目已有 HTML 技术方案，可借鉴其内容密度和视觉语言，但仍以本技能的页面契约为验收标准。
